# M2: Batch Path Ingestion

## Goal

Add a batch ingestion API that indexes existing markdown trees using a root path
and glob pattern while preserving the existing single-file ingest tool.

## Tasks

- [x] Add `KnowledgeBase.ingest_path`.
- [x] Walk only files below the requested root.
- [x] Support `glob_pattern`, `exclude_patterns`, and `max_files`.
- [x] Reuse existing `KnowledgeBase.ingest_file` for each matched file.
- [x] Return structured counts and per-file failures.
- [x] Rebuild the sidecar navigation index after successful markdown ingestion.
- [x] Add tests using a fake embedder.
- [x] Validate with compile and pytest.

## Validation
